# Examples

`clean.txt` – professionally edited Finnish (Kotus, "Kielenhuollon tehtävistä", accessed 2026-09-06). `with-errors.txt` – the same text with 7 injected errors:

1. missing comma before the relative clause: "toimintaa, jonka …"
2. tavoiteena → tavoitteena (typo)
3. ennenkaikkea → ennen kaikkea (wrongly fused)
4. kieli oppia → kielioppia (wrongly split compound)
5. "ja ja" duplicated word
6. missing comma between two complete main clauses: "tekstejä, ja monet …"
7. Suomalaiset → suomalaiset (nationality lowercase)

Voikko catches 2, 3, 5, 7 and hints at 1 ("saattaa puuttua pilkku"). Items 4 and 6 must be found by reading. Use this to sanity-check the skill after changes.
